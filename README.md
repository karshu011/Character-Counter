# 🔤 Character Counter

A simple and interactive Character Counter application developed using HTML, CSS, and JavaScript. This application helps users count characters and words entered in a text area.

## 🚀 Features

- 🔤 Count total characters
- 📝 Count total words
- 🔢 Display character count instantly
- ⌨️ Count characters while typing
- 🗑️ Clear entered text
- 📊 Display text statistics
- 🎨 Simple and user-friendly interface
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter or type text in the text area.
5. View the character and word counts instantly.
